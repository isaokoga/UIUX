# デザインプラグイン

Anthropic のエージェント型デスクトップアプリケーション [Cowork](https://claude.com/product/cowork) を主な対象として設計されたデザイン生産性プラグインです（Claude Code でも動作します）。デザインクリティーク、デザインシステム管理、UXライティング、アクセシビリティ、リサーチの統合、開発者へのハンドオフを支援します。どのようなデザインチームでも利用でき、あなたの入力だけでも単独で動作し、Figma などのツールを連携すると真価を発揮します。

## インストール

```bash
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install design@knowledge-work-plugins
```

## コマンド

スラッシュコマンドで明示的に呼び出すワークフローです。

| コマンド | 説明 |
|---|---|
| `/critique` | 構造化されたデザインフィードバックを得る — ユーザビリティ、視覚的階層、アクセシビリティ、一貫性 |
| `/design-system` | デザインシステムの監査・ドキュメント化・拡張 — コンポーネント、トークン、パターン |
| `/handoff` | 開発者向けハンドオフ仕様書を生成 — 寸法、トークン、状態、インタラクション、エッジケース |
| `/ux-copy` | UXコピーの執筆・レビュー — マイクロコピー、エラーメッセージ、空状態、オンボーディングフロー |
| `/accessibility` | アクセシビリティ監査を実施 — WCAG準拠、カラーコントラスト、スクリーンリーダー、キーボード操作 |
| `/research-synthesis` | ユーザーリサーチの統合 — インタビュー、アンケート、ユーザビリティテストを実行可能なインサイトへ |

すべてのコマンドは**単独で**動作し（デザインを説明するか、スクリーンショットを貼り付ける）、MCPコネクタを連携すると**さらに強力に**なります。

## スキル

関連する場面で Claude が自動的に活用するドメイン知識です。

| スキル | 説明 |
|---|---|
| `design-critique` | ユーザビリティ、視覚的階層、一貫性、デザイン原則への準拠の観点でデザインを評価 |
| `design-system-management` | デザイントークン、コンポーネントライブラリ、パターンドキュメントを管理 |
| `ux-writing` | 効果的なマイクロコピーを執筆 — 明確・簡潔・一貫性があり、ブランドに沿ったもの |
| `accessibility-review` | WCAG 2.1 AA 準拠の観点でデザインとコードを監査 |
| `user-research` | ユーザーリサーチの計画・実施・統合 — インタビュー、アンケート、ユーザビリティテスト |
| `design-handoff` | デザインから包括的な開発者向けハンドオフドキュメントを作成 |

## ワークフロー例

### デザインフィードバックを得る

```
/critique
```

Figma のリンク、スクリーンショットを共有するか、デザインを説明してください。ユーザビリティ、視覚的階層、一貫性、アクセシビリティについて構造化されたフィードバックを得られます。

### デザインシステムの監査

```
/design-system audit
```

コンポーネントライブラリを一貫性・網羅性・命名規則の観点でレビューします。具体的な改善推奨事項を含むレポートが得られます。

### UXコピーの執筆

```
/ux-copy error messages for payment flow
```

文脈に即したコピーを、トーンのガイダンス・代替案・ローカライズ上の注意点とともに得られます。

### 開発者へのハンドオフ

```
/handoff
```

Figma のリンクを共有すると、完全な仕様書が得られます。寸法、デザイントークン、コンポーネントの状態、インタラクションの注意点、エッジケースまで。

### アクセシビリティチェック

```
/accessibility
```

デザインまたは URL を共有してください。WCAG 2.1 AA 準拠レポートを、具体的な問題点・深刻度・是正手順とともに得られます。

### リサーチの統合

```
/research-synthesis
```

インタビューの文字起こし、アンケート結果、ユーザビリティテストのメモをアップロードしてください。テーマ、インサイト、優先順位付けされた推奨事項が得られます。

## 単独でも、連携でさらに強力に

すべてのコマンドとスキルは、連携なしでも動作します。

| できること | 単独（standalone） | 連携でさらに強力に |
|-----------------|------------|-------------------|
| デザインクリティーク | 説明またはスクリーンショット | Figma MCP（デザインを直接取得） |
| デザインシステム | システムを説明 | Figma MCP（コンポーネントライブラリを監査） |
| ハンドオフ仕様書 | 説明またはスクリーンショット | Figma MCP（正確な寸法・トークン） |
| UXコピー | 文脈を説明 | ナレッジベース（ブランドボイスのガイドライン） |
| アクセシビリティ | 説明またはスクリーンショット | Figma MCP、実利用データ向けのアナリティクス |
| リサーチの統合 | 文字起こしを貼り付け | ユーザーフィードバックツール（生データを取得） |

## MCP連携

> 見慣れないプレースホルダがある場合や、どのツールが連携されているか確認したい場合は、[CONNECTORS.md](CONNECTORS.md) を参照してください。

ツールを連携すると、より豊かな体験が得られます。

| カテゴリ | 例 | 実現できること |
|---|---|---|
| **デザインツール** | Figma | デザインの取得、コンポーネントの検査、デザイントークンへのアクセス |
| **ユーザーフィードバック** | Intercom、Productboard | 生のフィードバック、機能リクエスト、NPSデータ |
| **プロジェクトトラッカー** | Linear、Asana、Jira | デザインとチケットの紐付け、実装状況の追跡 |
| **ナレッジベース** | Notion | ブランドガイドライン、デザイン原則、リサーチリポジトリ |
| **プロダクトアナリティクス** | Amplitude、Mixpanel | リサーチの統合やデザイン判断のための利用データ |

サポートされている連携の一覧は [CONNECTORS.md](CONNECTORS.md) を参照してください。
