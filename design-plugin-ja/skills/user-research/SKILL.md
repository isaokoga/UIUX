# ユーザーリサーチ

ユーザーリサーチ調査の計画・実施・統合を支援します。

## リサーチ手法

| 手法 | 適した用途 | サンプルサイズ | 期間 |
|--------|----------|-------------|------|
| ユーザーインタビュー | ニーズや動機の深い理解 | 5〜8人 | 2〜4週間 |
| ユーザビリティテスト | 特定のデザインやフローの評価 | 5〜8人 | 1〜2週間 |
| アンケート | 態度や嗜好の定量化 | 100人以上 | 1〜2週間 |
| カードソーティング | 情報アーキテクチャの意思決定 | 15〜30人 | 1週間 |
| 日記調査（ダイアリースタディ） | 時間をかけた行動の理解 | 10〜15人 | 2〜8週間 |
| A/Bテスト | 具体的なデザイン選択肢の比較 | 統計的有意性に到達するまで | 1〜4週間 |

## インタビューガイドの構成

1. **ウォームアップ**（5分）: 打ち解け、セッションの説明をする
2. **コンテキスト**（10分）: 現在のワークフローを理解する
3. **深掘り**（20分）: 特定のトピックを掘り下げる
4. **反応**（10分）: コンセプトやプロトタイプを提示する
5. **まとめ**（5分）: 聞き漏らしはないか確認し、感謝を伝える

## 分析フレームワーク

- **親和図法（アフィニティマッピング）**: 観察結果をテーマごとにグループ化する
- **インパクト/工数マトリクス**: 発見事項に優先順位を付ける
- **ジャーニーマッピング**: 時間軸に沿ってユーザー体験を可視化する
- **ジョブ理論（Jobs to be Done）**: ユーザーがあなたのプロダクトを何のために「雇っている」のかを理解する

## 成果物

- リサーチ計画（目的、手法、スケジュール、参加者）
- インタビューガイド（質問、深掘りの問い、アクティビティ）
- 統合レポート（テーマ、インサイト、推奨事項）
- ハイライト集（重要な発言や観察のまとめ）
